# Support

Use GitHub issues for questions about adopting, teaching, or contributing to the course.

Before opening an issue:

1. Read the README, syllabus, and contribution guide.
2. Search open and closed issues for an existing answer or proposal.
3. Choose the closest issue template and explain the context in which you plan to use the material.

This project is maintained on a best-effort basis and does not provide emergency, commercial, or production-system support. Security concerns should follow [SECURITY.md](SECURITY.md), not a public support issue.
