# Security policy

## Reporting a vulnerability

Do not report a security vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository: open the repository's **Security** tab, choose **Advisories**, and select **Report a vulnerability**.

Include enough information to reproduce and assess the issue, but do not include credentials, personal data, confidential organizational information, or exploit activity against systems you do not own or have permission to test.

The maintainer will acknowledge a well-formed report when practical, assess its relevance, and coordinate any public disclosure with the reporter. This early-stage educational repository does not yet offer a formal response-time commitment or bug bounty.

## Scope

The current repository primarily contains curriculum and agent guidance. Security policies for future application and exercise repositories will be stated in those repositories and may differ according to their technology and instructional purpose.
