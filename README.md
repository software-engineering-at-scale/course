# Software Engineering at Scale

**Building, Operating, and Evolving AI-Assisted Systems**

This repository is the starting point for an open-source senior capstone course designed to prepare software engineering students to work in a mature software organization.

The premise is simple: students should not spend another semester building a disposable prototype from scratch. They should inherit a substantial system, use AI development tools to work at a scale they could not manage manually, and remain accountable for whether the resulting software is reliable, secure, maintainable, and ready to operate.

## The course in one sentence

Students use AI to investigate, change, test, operate, and hand off a large existing application while continuously defining what “done” means and proving that they achieved it.

## Why this course

AI has dramatically increased how much software a student can produce. It has not removed the need to clarify requirements, define acceptance, design tests, manage dependencies, protect security, understand performance, operate production systems, or take responsibility for failures.

This course is deliberately designed to require AI. The application, investigation, and pace of change should exceed what students could complete manually within a semester. Success is measured by the quality of the students’ decisions and evidence, not by the volume of code they generate.

## Influences

The proposal draws on ideas already present in leading software engineering courses, including Stanford CS 194, CS 210, and CS 224G; Berkeley CS 169A and 169L; and Carnegie Mellon 17-313, 17-316, and 17-423. The goal is not to claim that universities ignore software engineering practice. It is to combine proven elements into one AI-required simulation of building and operating software at scale.

This is an independent open-source project and is not affiliated with or endorsed by those institutions.

## Status

Early design. The first release begins with the syllabus so educators and working engineers can challenge the premise, improve the learning objectives, and help build the application and scenarios.
